
# 🌐 Interactive Portfolio Website

A responsive and interactive personal portfolio website built using HTML, CSS, and JavaScript. It showcases my skills, projects, and contact information while demonstrating JavaScript concepts such as DOM manipulation, event handling, form validation, and Local Storage.

## 🚀 Features

- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Dark/Light Mode:** Toggle between themes with preferences saved using Local Storage.
- **Interactive Project Slider:** Browse featured projects dynamically.
- **About Me Section:** Show or hide additional information.
- **To-Do List:** Add, complete, and remove tasks.
- **Contact Form Validation:** Validate name, email address, and message.
- **Live Character Counter:** Displays the number of characters entered in the message.
- **Mobile Navigation:** Responsive navigation menu for smaller screens.
- **Local Storage:** Saves theme preferences and to-do tasks.
- **Reusable JavaScript Functions:** Organized code for maintainability.
